# Design Archaeology 🏺⚡

**Stratigraphic provenance for netlists and floorplans** — detecting *vestigial
constraints* (design rules that no longer cause anything) with methods borrowed from
archaeology: stratigraphy, seriation, and residuality theory.

Everything — the flow engine, the edit grammar, the interventional oracle
(~2,500 place-and-route runs), the models, the deletion experiment, seriation, Harris
matrices, and all figures — runs in **one self-contained notebook**:

> **[`design-archaeology.ipynb`](design-archaeology.ipynb)** — CPU only, no internet.
> Upload to [Kaggle](https://www.kaggle.com/code) ("New Notebook" → File → Import
> Notebook), or run locally:
>
> ```bash
> pip install -r requirements.txt
> jupyter lab design-archaeology.ipynb     # then Run All, top to bottom
> ```

**Runtime: ~55 minutes on a laptop CPU**, single-threaded. (An earlier version of this
README said 5–10 minutes; that is wrong for the settings committed in cell 29 — see
[Compute budget](#compute-budget).) Cells share heavy state, so they must run in order.
For a few-minute smoke test that still exercises every code path, set `N_TRAIN=2`,
`N_EDITS=25`, `HELD_EDITS=30`, `HARRIS_PAIRS=16` in cell 29 — the headline metrics will
degrade accordingly.

## The idea

Mature chip designs accumulate sediment: inherited IP blocks, ECO patches on patches,
timing exceptions written for a process node three generations dead. The only way to know
whether a constraint still does anything is *relax it and re-run the flow* — too expensive
to do for hundreds of constraints. Archaeology formalized exactly this problem:

| Archaeology | Chip design |
|---|---|
| Stratum (deposition layer) | A revision / ECO / constraint-file edit |
| Harris matrix (which layers presuppose which) | DAG of which design decisions depend on which |
| Seriation (relative dating from artifact style) | Ordering edits from diff features when history is lost |
| Residual artifact | Vestigial constraint |

The notebook grows synthetic designs through an edit grammar (renames are the fossil
factory), labels every constraint with a real interventional oracle, then trains a cheap
learned surrogate that must beat the dead-referent linter.

## Experimental setup

| knob | value | where |
|---|---|---|
| training designs / held-out | 6 / 1 | `N_TRAIN`, cell 29 |
| edits per design | 65 (held-out: 75) | `N_EDITS`, `HELD_EDITS` |
| intervention seeds | `(0,1,2,3)` | `ORACLE_SEEDS` |
| noise-band seeds | `range(8)` | `BAND_SEEDS` |
| Harris pairs per design | 48 | `HARRIS_PAIRS` |
| band width | `max(2.5·σ·√(2/S), floor)` | `BAND_K = 2.5`, cell 11 |
| vestigiality / Harris threshold | 1.0 band | `VESTIGIAL_THRESH`, `HARRIS_THRESH` |
| noise floors | wns 0.012, tns 0.02, wl 0.45, cong 8.0, drc 40.0 | `NOISE_FLOORS` |
| QoR metrics | `wns, tns, wl, cong, drc` | cell 6 |
| relaxation levels | delete, loosen50, loosen10 (`false_path`: delete only) | `relax_levels` |

A constraint is **vestigial** iff its largest normalized effect, across all relaxation
levels and all five metrics, stays within 1.0 noise band.

Units are noise bands; `+` means the metric increased. wns/tns higher is better,
wl/cong/drc lower is better.

| deleted set | k | harm | gain | wns | tns | wl | cong | drc |
|---|---|---|---|---|---|---|---|---|
| model top-k | 19 | **0.05** | 4.37 | +1.96 | +4.37 | −0.88 | +0.05 | −0.45 |
| random k | 19 | 2.07 | 3.86 | −2.07 | +3.86 | +1.92 | +1.63 | −1.11 |
| linter (dead refs) | **0** | 0.00 | 0.00 | — | — | — | — | — |
| oracle (upper bound) | 25 | 1.58 | 4.27 | −0.17 | +4.27 | +1.14 | +1.58 | −1.19 |

> ⚠️ **The linter row is an empty set, not a safe deletion.** The dead-referent linter
> found *zero* constraints to delete in the held-out design, so its 0.00 / 0.00 is vacuous.
> This is the strongest form of the paper's claim, but the field report currently prints it
> in a way that reads like the linter performing safely — **fix the presentation before
> submission** (cells 22 / 41).

Note that the oracle's own set is *not* jointly safe (harm 1.58): individually-vestigial
artifacts interact, which is precisely the motivation for the presupposition DAG.

## Harris matrix

336 pairs tested across the 7 designs. Edges found per design: d0 0, d1 8, d2 2, d3 4,
d4 1, d5 2, held 4. Held-out: **4 / 48 pairs are edges (prevalence 0.083)**, classifier
**AP 0.80**, precision 0.67, recall 0.50. Edge A→B iff B's measured effect shifts by more
than one band when A is relaxed.

Sample size is the weak point here: 4 positive edges on the held-out design. Widen
`HARRIS_PAIRS` before making strong claims.

## Features (17, all parser-visible)

`t_clock`, `t_max_delay`, `t_false_path`, `t_region`, `t_keepout` (type one-hots);
`n_referents`, `frac_alive`, `any_dead` (referent liveness); `age_frac`,
`referent_recency` (stratigraphy); `fanout`, `overlap_cnt` (graph / geometry);
`slack_margin`, `geo_binding`, `rect_area` (binding); `static_dwns`, `static_dtns`
(static recheck without re-placement).

Cost: **one** baseline flow run per design, versus hundreds for the oracle.

## Models

Both `HistGradientBoosting*` with `max_depth=3, max_iter=220, learning_rate=0.08,
min_samples_leaf=4, l2_regularization=0.5, random_state=0`. The regressor fits
`log1p(effect)`. The Harris-edge classifier uses `max_depth=2, max_iter=120`.

Jupyter kernel. **Unexplained, and worth one controlled test**; if it holds, running the
experiment as a script would cut the wall clock sharply.

## Limitations (the honest trench walls)

- **Synthetic history realism.** The edit grammar is scripted; real revision histories have
  richer sociology (merges, reverts, tool-generated constraints). The corruption ablation
  is a start, not an answer.
- **Small designs, single toy flow.** A few hundred cells and a star-model placer stand in
  for a commercial flow. The mechanism transfers; the absolute numbers will not. Untested
  on commercial tools.
- **Noise-band sensitivity.** Labels depend on the band definition (~2.5σ of the Δ-of-means
  estimator, floored). The full paper should ablate it; here it is fixed.
- **Harris-edge sample size.** Pair tests are quadratic, so a biased sample is tested and
  edge recall is measured against partial truth.
- **Single run.** Every number above comes from one seed-set. Seed-level error bars are not
  yet computed.

**Why archaeology, really?** The discipline contributes the *label taxonomy*
(use / reuse / residual → active / repurposed / vestigial), the *DAG formalism* (Harris
matrices predate DAG-based build systems by decades), and the *evaluation frame* (relative
dating scored against stratigraphic truth). Method, not metaphor.
